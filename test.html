What is being compared

The MATLAB pipeline was checked line by line against the lab's original scripts. This page is a separate implementation of the same maths, so that check does not carry over. Below, this browser runs the same inputs MATLAB was given and the outputs are compared.

Db has to match exactly, because it is picked from a fixed grid of candidate values. A single differing value would mean the fit chose a different grid point. Continuous quantities are allowed to differ in the last few bits, which is unavoidable when arithmetic runs on a different platform.
