Verification

Runs this browser's maths against reference values produced by the lab's MATLAB pipeline.

Why this page exists

The MATLAB pipeline was verified line-by-line against the lab's original scripts. This web app is a separate implementation of the same maths, so that guarantee does not transfer automatically. These checks compare it against MATLAB output on real recorded data.

Db must match exactly — it is chosen from a discrete grid, so a single differing value would mean the fit landed on a different grid point. Continuous quantities are allowed to differ in the last few bits, which is unavoidable when arithmetic runs on a different platform.
